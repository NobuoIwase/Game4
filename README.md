# ルミナ・サバイバーズ — TEST BUILD v0.1

かわいくて清廉な光の少女**「ルミナ」**が主人公の、ヴァンパイアサバイバー風オートバトルゲームのテストビルドです。
ルミナはプレイヤーが操作せず、**ゲーム内AIが完全自動で行動**します(移動・回避・アイテム回収・レベルアップ時のビルド選択まで)。

## 起動方法

`index.html` をブラウザで開くだけです(Chrome / Edge / Safari 最新版推奨)。
ビルド不要・依存なしの単一HTMLファイルで、オフラインでも動作します。

## あそびかた(見かた)

- 「▶ テストプレイ開始」を押したら、あとは操作不要。ルミナちゃんを見守ってください
- **3分間サバイブでクリア**。2:00 にボス「ヴァンピロード」出現
- 敵を倒すと経験値ジェムがドロップ。レベルアップ時は AI が3択からアップグレードを自動選択します
- リザルト後は自動で再テストがループします(放置デモ可)

## 実装内容(テスト範囲)

| 要素 | 内容 |
| --- | --- |
| AI自動操縦 | 脅威回避 / ジェム回収 / ハート探索 / 距離維持(カイト)を状態機械+操舵ベクトルで判断。思考は吹き出しと画面左下の「AI思考」チップで可視化 |
| 武器 | ホーリーボルト(自動照準弾)/ セイントオーブ(周回光球)/ ピュアノヴァ(周囲一掃) |
| パッシブ | スピードシューズ / マックスハート / ジェムマグネット |
| 敵 | こうもり・ゴースト・ゾンビ(時間経過でHP強化)+ ボス(突進攻撃つき) |
| その他 | 効果音(WebAudio)・ベスト記録保存(localStorage)・微量リジェネ「清廉のご加護」 |

## デバッグ機能(テストビルド)

- `index.html?ts=3` … ゲーム速度3倍(1〜5)。バランス確認用
- ブラウザのコンソールから `__luna` でゲーム内部状態を参照可能
- 画面左下に敵数 / FPS を常時表示

## 既知の制限

- テストビルドのためバランスは暫定です(現状はクリア寄りの調整)
- BGMなし(効果音のみ)。モバイルは簡易対応(画面スケーリングのみ)
- ステージは1種、3分固定
