# ルミナ・サバイバーズ — v0.3「侵蝕デッキ」

ヴァンサバ風オートバトルの**立場逆転**ビルド。
光の少女**「ルミナ」**はゲーム内AIが完全自動で戦い(移動・回避・回収・ビルド選択・武器融合まで)、
**プレイヤーは夜側の指揮者**として、事前に組んだデッキから魔物を召喚して彼女を追い詰めます。

## 起動方法

`index.html` をブラウザで開くだけです(Chrome / Edge / Safari 最新版推奨)。
ビルド不要・依存なし・オフライン動作。データは localStorage に自動保存されます。

## ゲームの流れ

1. **出撃** — 3分間の観測戦闘。EN(エネルギー)を払い、カード+陣形で魔物を召喚
2. ルミナに魔物が倒されると **ENが還元**され、**エッセンス**が溜まる(彼女も経験値で強くなる)
3. 彼女のHPを削りきれば**捕獲**。与ダメージ・状態異常・捕獲で**オーブ**を獲得
4. **研究所**でエッセンスを使い、カード解放・強化・融合・陣形解放
5. **祭壇**でオーブを捧げ、ルミナの**初期状態そのものを書き換える**(永続)
6. ルミナは世代内(4戦)で経験を持ち越して強くなり、**世代が変わるとリセット**——
   祭壇の書き換えだけが残り続ける

## 戦闘の操作

| UI | 内容 |
| --- | --- |
| カード列 | クリックで召喚(コストは選択中の陣形で変動)。クールダウンあり |
| 陣形チップ | 散開 / 突撃列 / 精鋭 / 潜伏 / 包囲円陣(研究所で解放) |
| AUTO | オート指揮(拘束→重打のコンボ、熱の圧の維持などを自動判断)。既定値はホームで変更 |
| ▶ ×N | 戦闘速度(1〜3倍) |
| 撤退 | 2度押しで即時終了(獲得済みエッセンスは持ち帰り) |

## v0.3 実装内容

| 要素 | 内容 |
| --- | --- |
| モンスター | ナメクジ(接触魅了)/地上ワーム(四肢拘束)/ゴースト/粘スライム/**ガス玉(媚薬ガス滞留)**/**小淫魔(女の子型・まとわり煽り)**/触手花(脚に蔦)/融合2種(霧香スライム・大触手)/ボス |
| 四肢拘束 | 拘束役が接触すると**両腕・両脚に個別に絡みつく**。腕=攻撃低下、脚=移動低下、護り減。移動と攻撃で抵抗ゲージを溜めて引き剥がす(**スタミナ消費**) |
| スタミナ / 押し倒し | スタミナが薄い時に拘束されると**押し倒し**(もがきで脱出可)。**HPかスタミナが尽きると敗北=捕獲**。敗北スチルは assets/cg/ の画像を差し込み表示 |
| 媚薬 / 発情 | ガス・小淫魔の煽りで**媚薬ゲージ**が蓄積(即発情はしない)。満タンで一定時間の**発情状態**(集中・抵抗・回復が大幅低下) |
| 回復=燭台 | 回復ハートは彼女が**燭台を能動的に破壊した時だけ**ドロップ。回復の隙が攻めどころになる |
| ルミナ強化 | 武器3+パッシブ3+融合進化3、宝箱、世代システム(4戦で経験リセット/世代内継承) |
| 祭壇(オーブ) | 加護侵蝕・祝福遅滞・足枷・感応増幅・媚薬の残滓・朧の霞・**倦怠の澱(スタミナ弱体)** |
| 演出/フック | 四肢絡みつき描画・押し倒しゲージ・ガス雲・押し倒し中テキスト(scenes.js)・敗北スチル(assets/cg) |

## デバッグ

- `index.html?ts=N` … ゲーム速度N倍(1〜5)
- コンソール: `__game`(ランタイム状態) / `__meta()`(セーブデータ)
- 画面左下に敵数 / FPS 常時表示

## ファイル構成

```
index.html      シェル+CSS
js/core.js      基盤(ユーティリティ/オーディオ/セーブ)
js/data.js      全定義データ・バランス値(BAL)
js/scenes.js    シーンテキストの受け口(本文は別パイプラインで追加)
js/game.js      戦闘ロジック(ヒロインAI/モンスター/EN/オート指揮)
js/render.js    描画
js/ui.js        DOMスクリーン
js/main.js      起動・メインループ
docs/DESIGN.md  設計仕様
```

## 既知の制限

- バランスは暫定(数値は `js/data.js` の `BAL` に集約)
- 押し倒し/敗北シーンのテキストはフック(`js/scenes.js`)のみ。本文は別途執筆パイプラインで追加
- 敗北スチルは `assets/cg/defeat_<id>.png` / `defeat.png` を置くと表示(未配置なら注記のみ)
- ステージ1種・3分固定 / モバイルは簡易対応(横持ち推奨)
