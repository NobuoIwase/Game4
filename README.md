# ルミナ・サバイバーズ — v0.6「侵蝕デッキ」

ヴァンサバ風オートバトルの**立場逆転**ビルド。
光の少女**「ルミナ」**はゲーム内AIが完全自動で戦い(移動・回避・回収・ビルド選択・武器融合まで)、
**プレイヤーは夜側の指揮者**として、事前に組んだデッキから魔物を召喚して彼女を追い詰めます。

## 起動方法

`index.html` をブラウザで開くだけです(Chrome / Edge / Safari 最新版推奨)。
ビルド不要・依存なし・オフライン動作。データは localStorage に自動保存されます。

## ゲームの流れ

1. **出撃** — 5分間の観測戦闘。EN(エネルギー)を払い、カード+陣形で魔物を召喚
2. ルミナに魔物が倒されると **ENが還元**され、**エッセンス**が溜まる(彼女も経験値で強くなる)
3. 彼女のHPを削りきれば**捕獲**。与ダメージ・状態異常・捕獲で**オーブ**を獲得
4. **研究所**でエッセンスを使い、カード解放・強化・融合・陣形解放
5. **祭壇**でオーブを捧げ、ルミナの**初期状態そのものを書き換える**(永続)
6. ルミナは世代内(4戦)で経験を持ち越して強くなり、**世代が変わるとリセット**——
   祭壇の書き換えだけが残り続ける

## 戦闘の操作

| UI | 内容 |
| --- | --- |
| カード列 | クリックで召喚(コストは選択中の陣形で変動)。クールダウンあり |
| 陣形チップ | 散開 / 突撃列 / 精鋭 / 潜伏 / 包囲円陣(研究所で解放) |
| AUTO | オート指揮(拘束→重打のコンボ、熱の圧の維持などを自動判断)。既定値はホームで変更 |
| ▶ ×N | 戦闘速度(1〜3倍) |
| 撤退 | 2度押しで即時終了(獲得済みエッセンスは持ち帰り) |

| 要素 | 内容 |

| **絶頂** | 快感100で**絶頂**——脚が完全に止まり、痙攣して数秒動けない(移動・攻撃・抵抗・回復すべて停止、魔物は駆け寄る)。台詞は3段階(絶頂→痙攣→余韻)で流れ、下部のシーンテキストも表示。終わると発情が一段深まる |

| **潮吹きと染み** | 絶頂時、発情・敏感が深いほど潮を吹きやすい(35%+)。**地面に濡れた染みが残り**、ゆっくり乾いて消える(70秒) |
| **ドット絵ルミナ** | アップロードされたNovelAI画像を35×52・16色にドット化し、戦闘スプライトとして使用(assets/sprites/lumina.png)。差し替え・削除可(消すと従来描画)。原画は敗北スチル(assets/cg/defeat.png)としても使用 |

| **練度ゲート** | コンボ・夜の深まり・頭数ボーナスは**カードLvでスケール**(Lv1=無し/Lv2=半分/Lv3+=フル)。初戦の壁は保たれ、研究所投資で物量が解放される |
| **ヒロインの武器拡張** | 武器6種(+ウィップ/スターレイン/クロスブーメラン)+パッシブ6種+融合進化6種。武器枠4。**戦闘ごとにビルドの好みがランダムに偏り**、噛み合わない夜はDPS不足で物量に押し込まれる——ヴァンサバの「ビルド事故」を彼女が引く |
| **ヒロインの視界と思考** | 視界は**画面内のみ**(画面外の敵に気づかず、狙えない)。視認から反応まで遅れがあり、進路の判断は間隔を置いて更新される(境界ガクガクの排除)。ガス溜まりのジェムは基本見送るが、**多ければ意を決して取りに入る**——その隙が攻めどころ |
| **物量シフト** | EN上限 12+3×彼女Lv(最大60)・回復増・カードCD短縮。**コンボ**: 同カードを9秒以内に重ねると連鎖(×5まで)——召喚が強く・多くなる。**夜の深まり**: 彼女のLvに応じて召喚体が強化され、多数陣形の頭数も増える |
| モンスター | ナメクジ(接触魅了)/地上ワーム(四肢拘束)/ゴースト/粘スライム/ガス玉(媚薬ガス)/小淫魔(煽り)/触手花(蔦)/**ゴブリン(群れ)**/**吸液羽虫(吸い付き)**/融合2種/ボス |

| **敏感化/快感/発情** | 媚薬(ガス等)は**敏感化**を積む=快感の入りが増幅。刺激(吸い付き・煽り・絡みつき)で**快感**が溜まり、100で**発情レベル+1**(最大3)。発情中は**定期的に波**が来て攻撃と足が鈍り、深いと**魔物へ自分から寄ってしまう** |
| **吸液羽虫** | 肉質の小さな羽虫。掠めるように飛び、触れると**胸の先・秘部に吸い付いて**快感を注ぐ(3箇所まで・微スロウ)。拘束の有無を問わず取り付き、抵抗で引き離せる |

| 四肢拘束 | 拘束役が接触すると両腕・両脚に個別に絡みつく。移動と攻撃で抵抗ゲージを溜めて引き剥がす(スタミナ消費) |

## デバッグ

- `index.html?ts=N` … ゲーム速度N倍(1〜5)
- コンソール: `__game`(ランタイム状態) / `__meta()`(セーブデータ)
- 画面左下に敵数 / FPS 常時表示

## ファイル構成

```
index.html      シェル+CSS
js/core.js      基盤(ユーティリティ/オーディオ/セーブ)
js/data.js      全定義データ・バランス値(BAL)
js/scenes.js    シーンテキスト(押し倒し・魅了拘束・敗北の本文)
js/game.js      戦闘ロジック(ヒロインAI/モンスター/EN/オート指揮)
js/render.js    描画
js/ui.js        DOMスクリーン
js/main.js      起動・メインループ
docs/DESIGN.md  設計仕様
```

## 既知の制限

- バランスは暫定(数値は `js/data.js` の `BAL` に集約)
- シーン本文は実装済み。追加モンスターの本文は `js/scenes.js` のスキーマに追記
- 敗北スチルは `assets/cg/defeat_<id>.png` / `defeat.png` を置くと表示(未配置なら注記のみ)
- ステージ1種・5分固定(試験的に3分から延長) / モバイルは簡易対応(横持ち推奨)
