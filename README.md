# ルミナ・サバイバーズ — v0.2「侵蝕デッキ」

ヴァンサバ風オートバトルの**立場逆転**ビルド。
光の少女**「ルミナ」**はゲーム内AIが完全自動で戦い(移動・回避・回収・ビルド選択・武器融合まで)、
**プレイヤーは夜側の指揮者**として、事前に組んだデッキから魔物を召喚して彼女を追い詰めます。

## 起動方法

`index.html` をブラウザで開くだけです(Chrome / Edge / Safari 最新版推奨)。
ビルド不要・依存なし・オフライン動作。データは localStorage に自動保存されます。

## ゲームの流れ

1. **出撃** — 3分間の観測戦闘。EN(エネルギー)を払い、カード+陣形で魔物を召喚
2. ルミナに魔物が倒されると **ENが還元**され、**エッセンス**が溜まる(彼女も経験値で強くなる)
3. 彼女のHPを削りきれば**捕獲**。与ダメージ・状態異常・捕獲で**オーブ**を獲得
4. **研究所**でエッセンスを使い、カード解放・強化・融合・陣形解放
5. **祭壇**でオーブを捧げ、ルミナの**初期状態そのものを書き換える**(永続)
6. ルミナは世代内(4戦)で経験を持ち越して強くなり、**世代が変わるとリセット**——
   祭壇の書き換えだけが残り続ける

## 戦闘の操作

| UI | 内容 |
| --- | --- |
| カード列 | クリックで召喚(コストは選択中の陣形で変動)。クールダウンあり |
| 陣形チップ | 散開 / 突撃列 / 精鋭 / 潜伏 / 包囲円陣(研究所で解放) |
| AUTO | オート指揮(拘束→重打のコンボ、熱の圧の維持などを自動判断)。既定値はホームで変更 |
| ▶ ×N | 戦闘速度(1〜3倍) |
| 撤退 | 2度押しで即時終了(獲得済みエッセンスは持ち帰り) |

## v0.2 実装内容

| 要素 | 内容 |
| --- | --- |
| プレイヤー側デッキ | モンスター9種(融合2種・ボス1種含む)+陣形5種、EN経済、オート指揮 |
| 状態異常 | 拘束(被ダメ増・仕留めの窓)/ 発情(集中低下・ふらつき)/ 粘液(スロウ)/ 魅了(攻撃対象から除外) |
| ルミナ強化 | 武器3+パッシブ3+**融合進化3**(例: ホーリーボルト×スピード→シューティングスター)、宝箱 |
| 世代システム | 4戦ごとに戦闘経験リセット。世代内はHP/護り/初期装備を継承して強くなる |
| 祭壇(オーブ) | 加護侵蝕・祝福遅滞・足枷・感応増幅・微熱の種・朧の霞(世代を跨いで永続) |
| 観測記録 | ルミナのステータス画面(実効値・書き換え・堕ち二軸ゲージ・通算記録) |
| 演出 | 拘束の蔦/発情の熱気/魅了の視線FX、召喚魔法陣、捕獲シークエンス、生成BGM |

## デバッグ

- `index.html?ts=N` … ゲーム速度N倍(1〜5)
- コンソール: `__game`(ランタイム状態) / `__meta()`(セーブデータ)
- 画面左下に敵数 / FPS 常時表示

## ファイル構成

```
index.html      シェル+CSS
js/core.js      基盤(ユーティリティ/オーディオ/セーブ)
js/data.js      全定義データ・バランス値(BAL)
js/scenes.js    シーンテキストの受け口(本文は別パイプラインで追加)
js/game.js      戦闘ロジック(ヒロインAI/モンスター/EN/オート指揮)
js/render.js    描画
js/ui.js        DOMスクリーン
js/main.js      起動・メインループ
docs/DESIGN.md  設計仕様
```

## 既知の制限

- バランスは暫定(数値は `js/data.js` の `BAL` に集約)
- 捕獲シーン等のテキストはフック(`js/scenes.js`)のみ。本文は別途執筆パイプラインで追加
- ステージ1種・3分固定 / モバイルは簡易対応
