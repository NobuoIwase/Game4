# ルミナ・サバイバーズ — v1.4「侵蝕デッキ」

ヴァンサバ風オートバトルの**立場逆転**ビルド。
光の少女**「ルミナ」**はゲーム内AIが完全自動で戦い(移動・回避・回収・ビルド選択・武器融合まで)、
**プレイヤーは夜側の指揮者**として、事前に組んだデッキから魔物を召喚して彼女を追い詰めます。

## 起動方法

`index.html` をブラウザで開くだけです(Chrome / Edge / Safari 最新版推奨)。
ビルド不要・依存なし・オフライン動作。データは localStorage に自動保存されます。

## ゲームの流れ

1. **出撃** — 5分間の観測戦闘。EN(エネルギー)を払い、カード+陣形で魔物を召喚
2. ルミナに魔物が倒されると **ENが還元**され、**エッセンス**が溜まる(彼女も経験値で強くなる)
3. 彼女のHPを削りきれば**捕獲**。与ダメージ・状態異常・捕獲で**オーブ**を獲得
4. **研究所**でエッセンスを使い、カード解放・強化・融合・陣形解放
5. **祭壇**でオーブを捧げ、ルミナの**初期状態そのものを書き換える**(永続)
6. ルミナは世代内(4戦)で経験を持ち越して強くなり、**世代が変わるとリセット**——
   祭壇の書き換えだけが残り続ける

## 戦闘の操作

| UI | 内容 |
| --- | --- |
| カード列 | クリックで召喚(コストは選択中の陣形で変動)。クールダウンあり。右上のタグは階級(雑/中/大/王)、**「客」は宝箱から加勢した一時カード** |
| 陣形チップ | 散開 / **大散開** / 突撃列 / 精鋭 / 潜伏 / 包囲円陣 / **双璧**(研究所で解放)。**大型は精鋭/双璧のみ・ボスは単騎**——他の陣形を選んでいてもカード側に丸めた先の陣形名が表示される |

刻まれるのは呪いではなく、**快感の入り**と**同じ責めへの慣れ(振りほどきの速さ)**の両方。
だから堕ちても弱くならず、戦いは長引き、そのぶん激しくなる。

★閾値は机上ではなく実測から決めた。測らずに書いた最初の版は、走らせると
**25件中11件**しか刻まれなかった。「条件が1戦あたり何秒成立するか」を数えてから
置き直し、さらに床の性癖が「その床を離れた瞬間に溜まりを捨てる」形だったのを

## v6.3 — 据わった個体 / 巣窟の顔つき / ヤミコの武器 / 押し倒しの敷居

### 番兵が、掴んだまま連れ歩かれていた

`enemiesUpdate` は掴んでいる魔物を毎フレーム彼女の四肢の位置へ吸わせていた。
根が張っているはずの番兵も沼の触手も肉壁の口も、例外なく。

実測(番兵に掴ませて彼女を 360px 動かす):

| | 番兵が動いた距離 | 輪の中心から | 彼女との距離 |
| --- | --- | --- | --- |
| 前 | 233px | 261px(繋留 330) | 7px |
| 後 | **0px** | 59px | 36px(繋ぎ r=36) |

離した時に彼女の 7px 隣に立っているので、
「引き離してもしばらく移動した後、何も無い床でまた捕まる」ことになっていた。
`isSeated(id)` で据わった個体を一本化し、彼女の方を繋ぎの長さまで引き戻す形にした。

★`h.limbs[slot].r`(繋ぎの長さ)は、v6.2 まで**書かれるだけで誰も読んでいなかった**。
魔物が彼女に貼り付いていたので、繋ぎが働いているように見えていた。

### 巣窟の口で、入るか諦めるかを繰り返していた

原因は二つあった。

1. `ZONES.lewd.innate` が 1 で、嫌い方が最初から最大の 3 に張りついていた。
   `zoneFear = fear × max(innate, zoneKnow)` なので、**何度やられても振る舞いが変わらない**
   (実測: 知識0で 3.00・知識満でも 3.00)
2. 諦めるのは「その目標」だけだったので、同じ巣窟の中の別の物
   (宝箱を諦める→祠→ジェム…)を選び直して口の前へ戻っていた

実測(口の外に立たせて、決心がつくまで。各 n=30):

| | 決心まで | 迷い | 口の帯の出入り | 結末 |
| --- | --- | --- | --- | --- |
| 前 知識0 | 31.1s | 9.5s | 8.8回 | 入18 / 諦5 / 60秒でも決まらず6 |
| 前 知識3 | 35.6s | 9.8s | 8.8回 | 入11 / 諦7 / 決まらず10 |
| **後 知識0** | **1.3s** | 0.0s | 0.8回 | **入30**(軽い気持ちで入る) |
| **後 知識3** | **4.5s** | 1.0s | 1.3回 | 諦19 / 入10(さっさと諦める) |

あわせて迷いの長さを反転した。前は**覚えた地形の前でいちばん長く**(2.0〜3.6秒)
突っ立っていた。よく知っている所ほど、見た瞬間に決まる。

### 巣窟が、どの階でも同じ顔で同じ強さだった

仕掛けの数は全階 3/3/3 の固定、効きも階層に関係なく一定。
「入るとだいたい一瞬でピンチになる」の出どころ。

- `FLOORS[].lewd.mix` で階ごとに 陣/花/光線 の数・床の手の多さ・住み着く種を決める
  (1階 蜜の窪地 = 陣1 花1 光線0 手×0.85 媚茸2体 /
   12階 巻き戻しの褥 = 陣3 花3 光線5 手×1.4 枝触手2体)。
  住人は既にいる種から選ぶので、絵も図鑑も敗北本文も新しく書くものは無い
- `denPower()` = 1階 0.42 → 15階 1.22。入った瞬間の一撃・毎秒の火照り/敏感化・
  床の手の間隔・陣の効き・番人の太さに掛かる
  (最奥に20秒立たせた実測で、火照り 1階 9 → 15階 29)

### 序盤の押し倒しの敷居が、深いほど緩い逆さまの曲線だった

実測: 序盤14日 × 8周の敗北 13件のうち **12件が stamina 落ち、hp 落ちは 0件**。
その時の体力は 96〜100%。彼女は殴り倒されているのではなく、力尽きて押し倒されている。

原因は、押し倒しの敷居が絶対値 35 なのに、スタミナの最大値は階層で伸びること
(1階 1.00 → 15階 3.10 倍)。**1階では最大の35%、15階では11%**で押し倒される。
敷居を `min(35, 最大×0.20)` にして、浅い階だけを緩めた
(1階 20 / 5階 26 / 8階以降は 35 のまま)。

### ヤミコの武器3本が、形だけ他人の武器だった

闇の刃=ルミナのムチ / 闇の輪=フレイラの火の輪 / 闇の穿ち=ルミナの刃。
さらに ★**闇の輪は一度も描かれていなかった**(`p.dringR` を読む場所が無い)、
★闇の刃は `whipDark` を誰も読んでいないので**ルミナの桃色の光で描かれていた**。

- **闇の刃** — 振った跡が闇のまま宙に残り(最大4本)、跨いだ者を削る。
  彼女は斬った線を積み重ねて檻を組む
- **闇の輪** — 外から内へ締まり、触れた小物を内側へ引き込む(投網)
- **闇の穿ち** — いちばん**遠い**的を狙い、暗がりに立っているほど深く貫く。
  全員が近くを撃つ中で、この子だけが奥の暗がりを撃つ

### 媚薬沼の中の宝箱を、取りに行けなかった

二つの穴が重なっていた。

1. **「その沼の中に用がある時は避けない」という免除が、「もう浸かっている→外へ出す」の
   後ろにあった。** 沼へ向かう間は避けを切っておきながら、一歩でも浸かった瞬間に
   押し出しが働く。近づくと押し戻すが交互に効いて、縁で行ったり来たりになる
2. **深い沼の中の物の割り引きが ×0.30 と厳しすぎた。** 宝箱(価値3.0)でも 0.9 まで落ちて
   ジェムに負けるので、目当てになるのが一瞬だけ。浸かりかけては別の物へ乗り換える

免除を先に置き、割り引きを 0.45 に緩め、沼の中を目当てにしたら
渡りきるまで決め直さないようにした。

| 2階(浅瀬が多い・各 n=20) | 沼の縁の出入り | 宝箱に届いた | 決着まで |
| --- | --- | --- | --- |
| 前 | 13.1回 | 11/20 | 25s |
| 後 | **5.0回** | **15/20** | 18s |

5階(水の無い階)は 9.9→7.9回・11/20→13/20。
**浅瀬と重なった時にいちばん効く**——足が鈍るぶん押し戻しが相対的に強く、往復が長引く。

### フレイラの二本を、一つの熱で繋いだ

炎の剣はルミナのムチ、火の輪はルミナのオーブを色替えしただけの形だった。

- **炎の剣が当たるたび熱が溜まり(0〜5)、1.6秒当てないと冷める**
- 熱ぶん、炎の剣の火力が上がり、火の輪が広がって速く回る
- 熱が満ちた一振りは、通った床に火を残す

「気が強く、前に出る」を数値にしたもの——**退がると失う**。
二本が別々の札ではなく、一つの機関として噛み合う。

  実測: 6秒当て続けて 熱 5/5・火の輪 106px・床の火3枚 →
  相手を消して8秒で 熱 0/5・火の輪 73px。

### 武器の届く距離を、29本ぜんぶ測って直した

距離ごとに的を置いて 12秒あたりの削り高を数えた。

| 武器 | 前(60/260/520px) | 後 |
| --- | --- | --- |
| ひかりの刃 | 103 / 0 / 0 | **748 / 413 / 387** |
| クロスブーメラン | 411 / 0 / 0 | 411 / **192** / 0 |
| 火柱 | 679 / 0 / 0 | 679 / **416** / 0 |
| 霜の華 | 351 / 0 / 0 | 347 / **109** / 0 |

- **ひかりの刃**は `vx=±sp`・`vy≒0` の真横にしか飛ばず、斜めの相手に当たらなかった
  (全29本の最下位)。狙う相手の向きへ飛ばす
- **クロスブーメラン**は 500px まで相手を探すのに折り返しが 0.42秒固定で、
  360px/s × 0.42s = 約150px しか飛べていなかった
- **扇の開きが「角度の固定値」だった。** 枚数が2枚以上になると、どの一枚も
  狙った線に乗らない(260px 先で ±52px ずれる。当たり判定は 15〜17px)。
  ★これは弾数を増やす前からの穴でもある——
  **ふたごの鏡を取ると、十字が当たらなくなっていた**。
  ずらす量を「的の位置での横のずれ px」で決めるようにした

## v6.2 — 拘束から抜ける手立て / 繋がっていない定義を数える

### 拘束が「取られたら終わり」に寄りすぎていた

- **振りほどいた肢の猶予**(`REGRAB_GRACE` 1.15秒) — 触手を複数持つ相手で
  「剥がす→即つく→剥がれない」の輪に入るのを止める
- **「えいっ」** — スタミナを払って一息に振りほどく。肢を3本以上取られたか、
  押し倒されて5.5秒たつと試みる。**失敗すると力だけが抜けて熱が返る**。
  払って尽きればそのまま捕まるので、最後の一息を賭ける形になっている
- **奥義のスタミナ消費** — 13の技が払う。足りなければ撃てない
- **瞬間移動の壁越え** — 跳ぶ先に `losClear` を重ねた。★実測で壁を越えていたのは
  奥義ではなく `partyClamp`(二人を画面に収める引き寄せ)で、差分を一息に足して
  壁を貫いていた。6pxずつ刻んで壁で止めるようにしたら、離れ具合はむしろ改善した
  (枠の外に居た割合 4.91%→2.54%、はみ出しの最大 212px→120px)

### 繋がっていない定義を静的に数える(`check_dead.py`)

走らせても出ない種類の穴がある。定義はあるのに誰とも繋がっていないもの。数えたら20件出た。

- `hypnoObey`(忘れる従順) — 取れるが**効きを読む場所が無く**、何も起きない性癖だった
- `sniffT`(嗅ぐ発作) — 状態表示も反応も4箇所あるのに**引き金だけ無かった**
- `IMP_TEASE_CAP` — 上限が `Math.min(2, …)` と二重化していて、定数を動かしても効かない罠
- `PICK_FAMILY_MAX` — 「一階に1〜2株」と書いてあるのに常に1株
- 残り16件は設計が置き換わった後の置き土産。消さずに、なぜ残っているかを行に書いた

### 吸盤の輪で落ちる

通しテストを最後まで回せるようにしたら、`condTick` で落ちた。
`suckSlots` が返すのは**その瞬間の写し**で、輪の中の `applyPleasure` が絶頂を起こすと
そこで別の吸盤が外れる。肢では二度直してある同じ罠が、吸盤側に残っていた。
**計測の穴を塞ぐと、その先で本物の穴が待っている。**

| 要素 | 内容 |

### フレイラが沼のそばで炎のエリアを焚いていた

v5.0 の判定は「今いる場所から 炎の半径+沼の半径」だけを見ていた。炎は展開後も
十数秒ついて回るので、少し離れた所で焚いて、そのまま歩いて蒸発させられた。三段で塞いだ:

## v5.7 — 連続絶頂・スタミナの引き締め・催眠Ⅲ・フレイラの火力

### 何度絶頂してもスタミナが満タンだった

原因は二つありました。**抵抗の意志が 1.5/点でスタミナ上限を押し上げていた**こと
(実測225の内訳: 基礎100＋粘り48＋意志75)と、回復が 3.5/s と厚かったこと。
意志の寄与を 0.6/点、回復を 2.0/s(発情中は 0.4/s)に落としました。

### 連続絶頂

**絶頂の最中も弄られ続ければ、また快感が100に届きます。** 届くたびに硬直が伸び、
重なるほどスタミナを大きく持っていく(n回目 = 12 × (1 + 0.9n))。上限は4回重ね。

実測: 快感を注ぎ続けて30秒で **4回重なり・通算15絶頂・スタミナ100→0**。
これまでは同じ条件で満タンのままでした。絶頂が「済んだこと」ではなく「まだ続いていること」になります。

### 催眠Ⅲに届かなかった

二重の壁がありました。`HYPNO_GAIN[2]=34` で3発必要なうえ、減衰が 4/s で閃光の間隔に対して速すぎ、
さらに**意志が入りを `1-0.015×意志` で削る**——意志50なら **×0.25**。原理上Ⅲに届きません。
ゲインを 48(2発)、減衰を 3/s、意志の鈍りを 0.008(下限 ×0.45)にしました。

### フレイラに与ダメの倍率が一つも無かった

火力担当という設定なのに `hpMul`/`spdMul` しか持たず、**与ダメは素のまま**でした。
「火は届く所でしか働かない」という理屈で、近いほど強い形にしています。

| | 素100に対して |
| --- | --- |
| ルミナ(距離を問わず) | 161 |
| **フレイラ 零距離** | **176** |
| フレイラ 120px | 145 |
| フレイラ 400px | 114 |

加えてスタミナを削ったぶんの釣り合いとして、ヒロイン側の与ダメを全体で 1.12 倍しました。

## v5.4 — 居ない子の名前を呼んでいた

報告は一行、「フレイラがいないのに『フレイラ今の凄かった』という台詞が見えた」。原因は**名指しの台詞が、誰に向けたものかを教えられていなかった**こと。一件ではなく一族だった。

### 掛け合いの片方だけが落ちていた

雑談は二人ぶんの掛け合いで書いてある。コードは**居ない子の行だけを飛ばして、残りは喋らせていた**。

> ルミナ「フレイラ、いまの すごかった!」→ ~~フレイラ「当然。次はルミナの番」~~

返事が消えて、呼びかけだけが残る。フレイラが捕まって離脱した後に起きていた。**話者が全員その場に居る掛け合いだけを使う**ようにした。

### 名前が本文に直接書いてあった

「フレイラ! いま、はがす!」「これ、フレイラが つかって!」——二人しかいなかった頃の書き方が残っていて、**三人以上だとクウを助けながらフレイラの名前を呼ぶ**。22 行を `{o}` に替え、呼ぶ側が相手を渡すようにした。相手が決まらない場面では、名指しの行はそもそも使わない(「ねえねえ、あつまろ!」だけが残る)。

ただし**捕まった子の名前は、居なくても呼べなければならない**。「フレイラ!? そんな……!」はまさに連れて行かれた瞬間の台詞なので、そこは明示して呼べるようにしてある。

### ついでに見つかった二つ

- **かばう相手を取り違えていた**。台詞は「相方」の状態で選ぶのに、実際に助けに行くのは「いちばん調子の悪い子」。三人以上だと別人のことがあった
- **掛け合いが全部ルミナ＋フレイラだった**。v3.0 に書いたきり足していなかったので、**クウとヤミコは一度も雑談していない**。上の修正を入れると、フレイラが居ない場は完全に黙ってしまう。10 通りの組み合わせが埋まるよう 21 組を足し、**そもそも掛け合いの無かった第9〜12層**にも 12 組を書いた

### 菌輪の半径は 74 ではなく 470 だった

`BAL` に `RING_R` が二つあった。**後にある方が黙って前を上書きする。**

### 覚えた輪は、歩いて避ける

`learnTrap('ring')` は呼ばれていたが、**目当ての選定からしか外していなかった**。
だから輪の向こうへ行く時は、輪の上を素通りしていた。歩く舵にも回避を足した。
半径方向に押し返すだけだと行きたい向きと正面衝突してその場で止まるので、
**縁に沿って回り込む成分**(接線)を主にしてある。

| | 舵の曲がり(輪の中心を貫く向きとの角度差) |
| --- | --- |
| 覚える前 | **0°**(素通り) |
| 覚えた後 | **24〜29°**(止まらずに迂回) |

### 近い所でグルグル

「よく歩いているのに狭い円から出ていない」時間を測るハーネスを書いて再現した。
文脈が **かばい合い**(`cover:cover`)に偏っていた。

`coverTarget` の `coverUntil` ラッチは**両側で立ちうる**。そうなると互いを目標にして寄り、
`PARTY_SEP` の反発に押し戻され、その場で回り続ける。**調子の悪い方がかばうのをやめる**ようにした。

加えて、原因を問わず断つ検出器を入れた。12秒の窓で、歩いた距離が長いのに収まる円が小さければ、
かばいのラッチと目当てを捨てて、円の外へ向き直す。

嵌まりどころが二つあった。

1. **毎フレーム走る場所に置くこと。** 思考の拍は 0.1〜0.3 秒に一度しか来ないので、
