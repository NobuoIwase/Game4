## 1. 一行要約

街の灯を守る「眠らない側」の灯守ルミナが、街を眠らせる「夢の病」の源を断つために深淵を五夜かけて降りる——けれど街の大人たちが眠りの中で見ている夢の中身は、降りていく彼女自身で、その因果を彼女だけが知らない。プレイヤーは彼女がその夜どの夢に出会うかを選ぶ「夜の目」。手を触れることはなく、彼女の手記を読む。

## 2. 世界と深淵

### 2-1. 街と灯の掟
- 街に名はある。彼女は「街」としか呼ばず、手記にも書かない。名を言うと守るものが小さくなる気がするから。本文でも街の名は出さない。
- 古い決まりが一つ: **日没から夜明けまで、街の灯を一つも消してはならない**。各戸の成人は一つずつ灯を預かる(**灯の掟**)。灯守は夜通し街を回り、預かられた灯が消えていないことを確かめ、街に向けて**名乗る**——灯守が今夜も起きていることを告げる声で、変身の合図でもある。
- **灯を預かる者だけが、夢を見る。** 夜は灯を見る。深淵の息は「灯を預かる者の眠り」にだけ混ざる。灯を預からない者(子供)には届かない——だから夢の病に罹るのは街の成人だけで、**本作の登場人物は全員成人**。子供は物語にも寝室の描写にも登場しない(設定として不在にする。「子供だけは無事だった」のような言及もしない)。
- 街でいちばん多くの灯を見ている者は、灯守だ。全ての灯を確かめて回る目に、夜はいちばん早く気づいた。

### 2-2. 夢の病
- 街の外れ、古い洞の口から夜ごと甘い息が漏れる。街の大人たちはその息を眠りの中で吸い、朝には頬を火照らせ、寝具を湿らせて目を覚ます。**夢の中身は誰も覚えていない。**
- 眠りは日ごとに長くなる。やがて眠ったまま歩いて洞の口へ集まり、苔の上で見つかる者が出はじめた(「長く眠る者」)。街はこれを「夢の病」と呼び、源を洞の底——「深淵」と見た。
- 街の作法: 夢の病の者には**「枕元に帳面を置き、目覚めたらすぐ書け」**と命じる。夢の病の者は目覚めると夢を忘れるからだ。この作法が、彼女の手記の起源になる(6-4)。
- 薬師の帳面には「原因不明」とだけある。街の誰も、灯守が最初の患者だとは知らない。灯守本人も知らない。

### 2-3. 深淵
- 街の下、洞の底で脈打つ夜の心臓「魔核」の**眠りの深さが、そのまま五つの層**になっている。まどろみ(第一層)から最深の眠り(第五層)へ。各層の魔物は、その深さで魔核が見ている夢だ。
- 魔核の息が淫気で、**淫気は上へ昇り、像は下へ沈む**。息は洞を昇って街の眠りに混ざり、街の寝室の像は水面や花の奥や石の面に沈んで映る。
- 深淵は**夜明けに一度、大きく息を吐く**。街へ昇る息はこれで、眠りの深い者を洞の口まで運び、苔の上へ置く。街の人が眠ったまま口に集まっていたのは、この息に運ばれたからだった。
- 第四層「沈んだ回廊」はかつて灯の神殿で、先に降りた灯守たちとともに沈んでいる。石碑は先代たちの手記、封印石は先代たちが置いた「戻れ」の印(5-4)。

### 2-4. 彼女が降りる五夜、街の灯は
- 先代が「長く眠る者」になったあと、灯守は彼女一人。彼女が降りている五夜、街の灯は大人たちが順に回る**代番**が守る。灯は点く。ただし**名乗りは無い**——名乗れるのは灯守だけだから。
- 名乗りの無い夜、街は少し深く眠る。彼女はそれを知っていて、それでも降りる。「五夜で戻る」が街への約束で、賭け金でもある。

### 2-5. 時間の単位
- **一夜で一層。** 日没に降り、夜のうちに層を渡り、降り口に着けばそこで夜明けを迎える。夜明けは手記の時間。昼は降り口の灯りの下で「目を閉じるだけ」で過ごし(眠らない、と本人は言う)、次の日没に降りる。
- 捕まれば、その層に朝が来る(6-2)。二夜つづけて捕まれば、息が彼女を入口へ運ぶ(6-3)。

## 3. ルミナ

### 3-1. 名前・年齢・肩書
- **名前: ルミナ**(固定。街では「灯守(ともり)のルミナ」)。表示層で `《名》` トークンを使う場合も解決先はルミナのみ。
- **年齢: 成人**(十九。灯守を継いで二年目)。幼さは体格や年齢ではなく、**崩れたときに出る語彙と語尾**でだけ表す。
- 光の魔法少女としての呼び名「夜を照らす星」(称号)は街の子供向けの絵物語から来た古い呼び名で、彼女は照れながら否定しない。

### 3-2. 出自
- 街の灯守。先代——老いた女——から光の術と名乗りを受け継いだ。先代は手記でも口でも「先代」としか呼ばない(名は書かない。街の名を書かないのと同じ理由)。
- 灯守の仕事は、夜通し灯を確かめて回ること。だから彼女は街でただ一人の「眠らない側」で、それを職務ではなく**身分**のように思っている。

### 3-3. 目的(三層)
1. **表**: 夢の病の源を断ち、街を起こすこと。表向きはこれで全部。
2. **裏**: 夢の病の最初の夜、見回りの途中で眠りこけた一夜の寝過ごしが、先代を眠らせた——その負い目を、源を断つことで返したい。
3. **奥(本人も口にしない)**: 自分が「眠らない側」であることを、毎朝自分に証明し続けたい。**降りるのは街のためで、降り続けるのは自分のためだ。**

### 3-4. 傷
- 夢の病が街に現れた最初の夜、彼女は生涯で一度だけ見回りの途中で眠りこけ、朝まで目覚めなかった。目覚めたとき下着が湿っていて、寝汗だと決めた。その夜、先代の家の前の灯が消え、先代が最初の「長く眠る者」になった。
- 彼女が結んだ因果: 「私が灯を消したから、夜が入った」。
- 真実は逆。その夜、夜の心臓が灯りに気づいて彼女のほうへ寝返りを打った。**彼女が街で最初の患者で、寝過ごしは最初の症状だった。** 以来、彼女は深く眠らない。眠れば、あの朝の湿りがまた来る気がしている。それを誰にも言っていない。
- この真実を本文で彼女に言わせない。総評(夜の目の筆)と第五層の脈光だけが知っている。

### 3-5. 矜持
- **「灯を消さない側は、眠らない」。**
- 毎朝、街の作法どおり帳面に一行——**「夢は見なかった」**——と書く。この一行が彼女の誇りの全部で、一度も嘘を書いたつもりがない。
- **名乗り**(全文固定。本文で変えない。崩れは途切れで表す):
  > 「私は、光の魔法少女——灯守のルミナ。今夜も、起きてるよ。街の灯は、一つも消させない」
- 価値を預けている先は**「起きていること」**。夜が書き換えるのはそこだ(第五層で「守る者」から「見られていた者」へ)。崩れるときは、この一行と名乗りが最後まで残り、最後に軋む。

### 3-6. 崩れ方の核と、崩れたあとの新しい矜持
- 崩れ方の核は聖書どおり——**口語の軽さが壊れて幼い素が出る**。「〜だし」が消えて素の悲鳴になる。
- ただし本作では、崩れの上に一段だけ**新しい矜持**を置く(案Aから移植)。二世代目以降、第三層で自分の手記の取り消し線の意味を身体で理解した彼女は、**消した字を消さずに残す**ことを選ぶ。「消したら、書き直したのが嘘になる。線は残す」。読まれることを受け入れる形の、小さくて、より正直な誇り。夜の目はこれを読める。読めるからこそ、彼女はそれを誇りにする。

### 3-7. 声の文法表(ルミナ・本作版)

| 項目 | 内容 |
|---|---|
| 一人称 | **私**(平静)/ **あたし**(崩壊・素が出たとき)。切り替えは「〜だし」が保てなくなった拍から |
| 語尾 | 〜だよ / 〜じゃん / 〜だし。言い張るときは「〜だし」を重ねる(「ちがうし。ちがうって言ってるし」) |
| 地の文 | 常体・軽い。読点は間引く。部位名は言い切る(手記の中だけ婉曲を許す) |
| 心の声 | （出た、テンプレ）（……見られてる、わけない） |
| 得物・小物 | 光の術(ボルト/ノヴァ等の既存武器)・灯・帳面(手記)とペン・髪留め |
| 崩れ方の核 | 口語の軽さが壊れて幼い素が出る。名乗りが途切れる |
| 崩壊時の残滓 | 「〜だし」が消えて素の悲鳴に。最後まで残るのは「夢は見なかった」の一行と名乗りの冒頭「わたしは——」 |
| 幼い語(崩壊でだけ) | とんとん、おこさないで、たすけて、ちがうもん(多用禁止・一場面に一つ) |
| 禁止語 | 武家語・古語・祈り言葉・典型的女性口調(〜だわ/〜のよ)・「催眠」「淫気」「魅了」等の夜側の用語を自分で名指しすること |
| 罪悪感の宛先 | 眠っている街(の大人たち)/ 先代 / 手記を読む者(夜の目) |
| 羞恥の向き | 「されたこと」より**「読まれること」**。だから手記の話になると強がる(「好きに書いて」) |

### 3-8. 言い訳の連鎖(層ごとの決まり文句)
抵抗の解像度は、言い訳の解像度で作る。層が下がるごとに言い訳は具体的になり、同時に薄くなる。
- 第一層: 「反響」「苔が濡れてるだけ」
- 第二層: 「湿気のせい」「落ちた(=足を取られた)」「水が遅いだけ」
- 第三層: 「みんな熱があるんだよ」「まばたきしただけ」「花粉」
- 第四層: 「似てるだけ」「読めばいいんでしょ」「石が、勝手に」
- 第五層: 「呼んでたのは、たすけての、ほうだし」「疲れ」
- 朝(再挑戦): 「寝てない。倒れてただけ」「服が乾いたら行く」
- 朝(入口): 「下の空気で頭が飛んだ」「病気の人たちとは、ちがう」

## 4. 夜の意志(魔核)とプレイヤーの立ち位置

### 4-1. 魔核
- 街の下、深淵の最奥で脈打つ肉の心臓。**動かず、追わず、選ばない。ただ眠っていて、眠りながら夢を見る。**
- 吐く息が淫気で、息は洞を昇って街の眠りに混ざる。五つの層は魔核の眠りの深さ、各層の魔物はその深さで見る夢だ。
- 魔核は彼女を**憎まない。崇めもしない。** 灯りがまぶたの裏に入ったから、そちらへ寝返りを打っただけ——執着ではなく、無関心な寝返り。街を守る光が、夜にとっては寝返りの向き先でしかない。
- だから魔核は**彼女の格を参照しない**。誇りを認めず、名乗りを聞き分けず、覚えかけの身体を「初見のほうが甘い」と入口へ吐き戻す(6-3)。
- 魔核が欲しいのは彼女の敗北ではなく、**彼女が繰り返し降りてくること**。夢は、夢に出てくる者が戻ってくる限り続く。
- **魔核は喋らない。脈で言う。** 最深部で見せるものは言葉ではなく、街じゅうの寝室と、その眠りの中身だ。魔核に台詞・思考・名乗り返しを書かない。実装の魔核(根の鞭・脈動・床から手)は全て「寝返り」と「寝息」の範囲で描く。
- 夜の分類には一つ誤りがある。彼女の**抗い癖(抵抗の意志)**を、夜は「癖」の側に数えて残してしまう。負けるほど強くなるものが、彼女の中にそれ一つだけある。総評はこれを「夜側の唯一の見落とし」と呼んでよい。

### 4-2. プレイヤー=「夜の目」(観測者)
- 魔核は動けず選べない。**その注意——どの夢を、どこに、どの順で見せるか——を担うのがプレイヤー**で、それが召喚・陣形・アイテム設置に当たる。研究所は夢の組み合わせ、祭壇は「夢の底に置く供物」——彼女の初期状態を夢のほうから書き換える行い。
- 夜の目は**彼女に触れる手を持たない**。触れるのは夢(魔物)。夜の目は見て、記録し(総評は夜の目の筆)、彼女の手記を読む。
- 彼女は手記を読む者がいることをうすうす知っていて、「好きに書いて」と強がる。その強がりまで含めて観測の対象になっている。
- 夜の目を直接の凌辱者にしないのはこの構図を守るため。彼女の羞恥はいつも「されたこと」より「読まれること」に向く。
- 彼女は夜の目の**姿を最後まで見ない**。第二層で「見られてる」と初めて気づき(水鏡の半拍遅れ)、第五層で街じゅうが自分を見ていたと知る。夜の目そのものは、気配と、石に刻まれた筆跡でだけ存在する。
- 街じゅうの眠りが彼女の夢を見ている構図は、**夜の目の鏡像**。観客は街で、観測者はプレイヤー。二つは重ねて書いてよいが、同一だとは言わない。

## 5. 五階層 — それぞれの意味と出来事

各層に共通して書くもの: **意味** / **出来事(初代)** / **二世代目以降の差分**(META.gen.idx≥2) / **名乗りの弧**(段) / **物語文の帯の基準線**(案Bから移植) / **手記の頁** / **総評の補記(比較)**。
帯の基準線は「その層の物語文(導入・降下・朝)が見せる深さ」を決める。場面本文(拘束・敗北)は実装の状態(fallTier)に従い、層では決まらない。二者が食い違うときは物語文の言い訳が吸収する(浅い層で状態が深い→「昨日のが、残ってるだけ」)。

### 5-1. 第一層 入口の洞 —— まどろみの層
- **意味**: 深淵が「吐き戻す」場所。夢の病の者が眠ったまま歩いて集まり、朝に苔の上で見つかる口。彼女がここに立つのは「眠らない側」の名乗りを置くため——賭け金を置く場所。同時に、二連敗のたび彼女自身が知らずに戻される場所でもある。まだ光が届く。だから、何も起きていないと信じられる。
- **出来事(初代)**: 苔が人の大きさにへこんでいる。腰の形、握った指の形、灯油の匂いが残る夜着の切れ端。ここで見つかった大人たちを、彼女は全員背負って街へ帰した。へこみの脇の**石棚**に、灯守の作法どおり「入った印」を一本刻む——先代もそうしたと教えられた。石に線は一本もない。彼女は灯を掲げ、名乗る。洞が名乗りを返す——**半拍遅く、少し低く**。「反響」と言って歩き出す。夜の目だけが、夜が今夜の名を覚えたことを知る。
- **二世代目以降**: へこみの一つが**まだ温かい**。自分の大きさだとは、確かめない。石棚には**正の字の線が世代の数だけ**ある(案Aから移植)。彼女は数えられる——「七本。先代たちの印だ。ここまでは、みんな来てたんだ」——が、刻んだ日を一つも思い出せない。全部同じ深さ、同じ手の角度で刻まれていることは、石が硬いからだと片づける。そして自分の一本を足す。
- **名乗りの弧・段0**: 洞が半拍遅れて返す。
- **帯の基準線**: **first / resist**。格を積む層。触れられる事実だけが恥で、手記は冷静な対策で終わる。ここでの物語文に喘ぎを置かない。
- **手記の頁**: 「入口の洞。苔と水。へこみ、七つ。ぜんぶ背負った。……夢は見なかった。」対策一行で終わる。二世代目以降、朝の頁は**自分の字の「追記」を読む**場面になる(6-3)。
- **総評の補記**: 「入口の石に線が n 本。彼女は先代の印だと思っている。先代の印は一本も無い。」

### 5-2. 第二層 水鏡の洞 —— 浅い夢の層
- **意味**: 淫気は上へ昇り、像は下へ沈む——止まった水面は街の寝室を映す鏡になる。「見る側」が「見られる側」へ反転する最初の場所。清水で洗い流せる、と彼女がまだ信じている層でもある。浅瀬に沈んだ落とし物は、運ばれた者たちのものだ。
- **出来事(初代)**: 止まった水に街が映る。寝台、火照った頬、動く唇——「ひかり……」。彼女は救いを呼ぶ声だと受け取り、水面に「待ってて」と言う。身を乗り出すと自分の顔が眠る者の顔に重なり、火照りの色が同じになる——湿気のせいにする。**自分の像だけが半拍遅れる**(案Aから移植)。こちらが顔を上げたあとも、水の中の自分はまだ水を見ている。「水が遅いだけ」。これが彼女が「見られてる」と初めて思う瞬間で、誰に、とは考えない。浅瀬で足を取られ、清水に浸かって「落ちた」と言う。自分の周りの水だけがぬるいことには触れない。
- **二世代目以降**: 浅瀬に自分と同じ**髪留めが錆びて沈んでいる**。「同じ店で買ったんだね」。
- **名乗りの弧・段1**: 名乗ると水面の街の唇が同じ拍で動く。返事ではない、と彼女は思う。
- **帯の基準線**: **strain(綻び)**。言い訳が一つ増える層。清水で「流す」動作が儀式になり、流しても残るものがあることに本人だけ気づかない。
- **手記の頁**: 初代は欄外に「※水がぬるい。温泉が近いんだと思う」。二世代目以降、本文に最初の取り消し線が現れる(「~~見られ~~ 映ってただけ」)。
- **総評の補記**: 「水鏡に映った寝室は n 室。彼女は救いを呼ぶ声だと書いている。呼ばれたのは名で、求められたのは救いではない。」

### 5-3. 第三層 蜜の花園 —— 甘い夢の層
- **意味**: 淫気が最も濃く、花が吐く息そのものが街の眠りの中身——街の大人が夜ごと見ている夢の、内側。彼女にとっては「洗い流せる」から「慣れる」への境目で、深淵で初めて、知らずに眠る層。侵蝕が自覚のないまま身体に住みはじめる。
- **出来事(初代)**: 花弁の奥から寝言が漏れる。街の声だ。「ひかり……」に、今度は「ルミナ……」が混じり、その声の質は救いを呼ぶものではない——彼女は「みんな熱があるんだよ」で片づける。花粉を落とすためだけに温泉へ入る。まばたき一つのつもりが、開けた目に映る**湯気の高さが違い**、口の中に花弁が一枚ある。**小淫魔**が現れ、指一本触れずに実況する(案Bから移植)——「いまねー、街のみんな、この顔見てるよ♡ まぶたの裏で、ぜーんぶ♡」。実況の中で名乗ろうとして、**途中で言えなくなる**。その夜、降り口で「夢は見なかった」と書く。翌朝、欄外に自分の字で「あまい」とあるのを、書いた覚えがないまま塗り消す。
- **二世代目以降(取り消し線の三段・案Aから移植)**:
  1. **初代**: 欄外の「あまい」をぐりぐり塗り消す(ほぼ読めない)。
  2. **二世代目**: 本文の中に「~~甘い~~ 使える」の線がある——過去の自分の字だ。読んだ夜、蜜の花の前で今日の自分の手が**同じ字を書いて、同じ線を引く**。そこで彼女は理解する。**取り消し線は快楽の告白ではなく、身体が別のことを言っている最中に、それでも対策を書こうとした手の跡**だ。「あの線、負けた印じゃない。書き直した印だ」。
  3. **三世代目以降**: 彼女は線を消さなくなる。細い一本線で「甘い」が読めるまま残り、横に書きなぐりで「使える。線は消さない」。読まれることを引き受けた形の新しい矜持(3-6)。夜の目はその頁を読める。
- **名乗りの弧・段2**: 小淫魔の実況に張り詰めて、名乗りが途中で切れる(「わた、し、は……ひかりの……ま、ほ——」)。切れた先を言うのは彼女ではなく、花弁の奥の寝言だ。
- **帯の基準線**: **yield(心は拒み、体は応える)**。物語文に初めて喘ぎの帯(low〜mid)を許す。♡は小淫魔の台詞にだけ。
- **手記の頁**: 「蜜の花。花粉で肌が。温泉に入った。まばたき——」で行が変わる。ここが手記の山場。
- **総評の補記(比較)**: 「先代の灯守は第三層で三夜まどろんだ。彼女は一夜で目を開けた。開けた目に映る湯気の高さが違っていたことは、本人の記録に無い。」

### 5-4. 第四層 沈んだ回廊 —— 忘れられた層
- **意味**: かつて灯の神殿だった石畳が、先に降りた灯守たちとともに沈んでいる。封印石は魔核を閉じるためではなく、灯守がこれより深く降りないよう置かれた**「戻れ」の印**——灯守の名乗りでしか灯らないよう作られ、つまり**誇りの高い者ほど開けてしまう錠**。先代たちの忠告を、自分の名乗りで解く場所。石碑は先代たちの自筆の手記で、彼女はそれを読んで知識を得る——自分の手記を読む朝の、予行になっている。
- **封印石=夜の図鑑(案Aから移植)**: 封印石は三つ(実装どおり順不同)。**石碑(先代の自筆・本人の筆)**に対して、**封印石は夜の目の筆**で刻まれている——総評と自己評価の二層を、レベルそのものに持たせる。
  - **称号の石**: 先代灯守たちの称号。「良い語×悪い語」の対置(例:『不落の灯にして、花床の眠り姫』『三夜を数えた灯守、数えられた身体』)。
  - **観測の石**: 夜の目の観測記録——総評の写し。先代たちがどの層で何夜まどろみ、どこで戻れなくなったか。
  - **彼女の石**: 彼女自身の記録。**まだ途中**。称号と総評の文体で彼女の堕ちが刻まれていて、名乗りで灯すには、そこに刻まれた自分の記録を**名乗りの声で読み上げる**ことになる(白状の反転——書かされるのではなく、書かれたものを読まされる)。
  - 降り口が開く理由: 夜は**結末を読みたい**。だから通す。降り口は溜め息のような音で開く。
- **出来事(初代)**: 封印石の前で名乗るごとに回廊が名を返し、返りが**一つずつ早くなる**(一つ目: 半拍遅れ/二つ目: 同時/三つ目: 言い終える前に返る——**夜のほうが先に言う**)。順不同なので、早さは「何番目に灯したか」で決める。彼女の石の脇、壁の低い位置に爪で刻まれた線がある。「四つめは水の側。読んだら、信じて。」——初代では見知らぬ者の跡。
- **二世代目以降**: 爪の線は**自分の字**だ。「似てるだけ」。彼女の石の記録が前より長い。読み上げる行が増えている。
- **名乗りの弧・段3**: 夜のほうが先に言い終える。名乗りの主が入れ替わる。
- **帯の基準線**: **crave 手前——「書けない」**。物語文の喘ぎは high まで。手記の行が途中で切れる。それでも♡は置かない(まだ懇願ではなく、言葉が出ないだけ)。
- **手記の頁**: 「石碑を三つ読んだ。先代の字。……封印石の字は、先代じゃない。誰の字。」行が途切れ、次の朝の一行だけがいつもの字で書かれる。
- **総評の補記**: 「三つの石の前で、名乗りは三度とも言い切られた。三度目は、言い切る前に石のほうが終えていた。彼女はそれを『石が勝手に』と書いている。」

### 5-5. 第五層 肉の巣 —— 最深の眠り
- **意味**: 夢と夢を見る者の境目が消え、夢に身体があった場所。壁も床も脈打ち、その拍は彼女の心臓ではなく、**街じゅうの寝息の拍**だ。魔核の間で、彼女は自分が「守る者」ではなく「見られていた者」だったと知る——**価値の参照先がここで書き換わる**。それを知ったまま、なお名乗って戦う層。
- **出来事(初代)**: 床の拍を数えるうち、個々の寝息が聞き分けられる。**先代の、少し掠れた寝息**。「街の寝息だ」。魔核の脈光が街の寝室と、その眠りの中身を映す——入口の苔で、水鏡で、花床で、回廊で。**どの夢にも自分がいる。** 彼女は名乗る。今度は洞は返さない。返ってくるのは**上から、街じゅうの寝言で**——「ルミナ……」に、先代の掠れた声が混じる。それを聞きながら光を構える。魔核は避けない。避ける必要を、一度も感じていない。
- **二世代目以降(並べて採点・案Aから移植)**: 脈光は街が見た夢=**前の世代の彼女の降下**を、今の彼女と**並べて**映す。どの層で何度沈んだか、何度鳴いたか——数が出る(実装の捕獲回数・絶頂回数・世代数をそのまま使う)。彼女は前の自分を「知らない」と言い、数を「なんで出てるの」と言い、最後に「あたし、いま、何回目——」で言葉が切れる。夜の目は数え、彼女は数えない。数えないことが、この層での最後の抵抗になる。
- **名乗りの弧・段4**: 返事が上から、街じゅうの寝言で来る。名乗りは「灯守が起きている合図」から「街が見ている夢の題」へ、参照先を書き換えられる。
- **帯の基準線**: **crave(待ってしまう)**。物語文に♡を許す唯一の層(壊れ/懇願の行のみ。地の文には書かない)。それでも最後の一行は名乗りか言い訳で締める。
- **手記の頁**: 言葉が無い。心臓の絵が何度も描かれ、線が震えている(既存 `CODEX.core.note.after` と一致)。頁の隅に、拍を数えた印だけがある。
- **総評の補記**: 「最深部で名乗った。返したのは深淵ではなく、街だった。彼女は『たすけて、のほう』と書いている。書いた手の字は、入口の頁と同じ字ではない。」

## 6. 日々の構造

### 6-1. 一夜一層のリズム
1. **日没**: 降り口(初日は入口)で灯を掲げ、名乗る。降りる。
2. **夜**: 層を渡る。降り口にそばに立てば(実装: 2.5秒)、その層はそこで終わる。
3. **夜明け**: 降り口の灯りの下で手記を書く。まず魔物の頁(図鑑の追記)、次に日々の頁の一行「夢は見なかった」。
4. **昼**: 手記を胸に抱いて**目を閉じるだけ**。「まどろみ」と本人は呼ばない。「目を休めてるだけ」と言う。眠っていない、と翌朝の一行に書く。
5. 次の日没へ。

### 6-2. 捕まる=夢に落ちる(再挑戦)
- 深淵で捕まることは、夢に落ちることだ。一度なら**同じ層に朝が来る**。身体は湿り、記憶は途切れているが、層は覚えている(実装: 地形・場所の記憶は再挑戦で保つ)。
- 朝の彼女の決まり文句: 「ちがうよ、寝てない。倒れてただけ。倒れてたのと寝てたのは、ちがうし」「服が乾いたら行く」。その朝も「夢は見なかった」と書く。
- 再挑戦の夜の物語文は、初回と**別の本文**にする(反復抑止)。差分の芯は「同じ場所に二度立つ」ことの羞恥——同じ苔、同じ水、同じ花の前で、身体のほうが先に道を覚えている。

### 6-3. 二連敗=夢が根を持つ(リセット・世代)
- 二夜つづけて落ちると夢が「根を持つ」。深淵は夜明けに息を吐く(淫気が街へ昇る、その息だ)。息は眠りの深い者を洞の口まで運び、苔の上へ置く。街の大人が眠ったまま口に集まっていたのと**同じ運ばれ方**で、彼女は同じ苔に置かれる。
- **息が持っていくもの=「覚え」**: 抗って身につけた熱、武器の育ち、避け方、道順、何日降りたかの記憶。夜は覚えかけの身体を好まない。初見の怯えのほうが甘いので、彼女を降りる前の身体に戻して吐き出す。
- **息が置いていくもの=「癖」**: 身体に植わった性癖、呪いの残り香、祭壇で書き換えられた初期状態。覚えは彼女の役に立ち、癖は夜の役に立つ。夜は自分の役に立つものだけ残す。
- **夜の見落とし**: 抗い癖(抵抗の意志)と、世代を跨いで少しずつ上がる土台(加護の一部)。夜はこれを「癖」の側に数えて残してしまう。負けるほど強くなる、彼女の中の唯一のもの。

| 物語の言い方 | 実装 |
|---|---|
| 息が持っていく「覚え」 | `META.gen.know / zoneKnow / trapKnow` の破棄、`META.rot` のリセット、武器・レベルは戦闘ごと、`luminaDecay()` で加護が数段薄れる |
| 息が置いていく「癖」 | `META.traits`(性癖)、`META.curse`(ボス敗北の呪い・残り日数)、`META.altar`(祭壇の書き換え) |
| 夜の見落とし | `META.lumina.will`(抵抗の意志)、世代ごとの素の+3%、薄れきらない加護 |
| 手記 | `META.codex`(魔物の頁)と日々の頁。紙とインクは喰われない |
| 読んで知っただけ | 追記二以上の種族の知識を次の世代で一段だけ引き継ぐ |
| 街の眠りの深さ | `META.gen.idx`(世代)。世代が進むほど街は深く眠り、魔核は厚くなる(CORE_HP +8%/世代) |

- **入口で目覚める朝**: 彼女は着いたばかりだと思い、灯守の作法どおり石棚に一本刻もうとして、線がすでに並んでいるのを見る。抱えたノートを開き、自分の字で書かれた「追記三」を読む。書いた覚えがない。「下の空気で頭が飛んだ。長く居すぎた。病気の人たちとは、ちがう」と結び、その朝も「夢は見なかった」と書き足す。
- 図鑑の手記がひとつのノートの中で追記ごとに乱れていくのは、**それが幾世代ぶんの彼女の字だから**だ。彼女が手記から魔物の知識を一段だけ引き継ぐのは、読んで知っただけで、身体は知らないからだ。
- 街の側では、世代が変わるごとに眠りが一段深くなる。彼女が忘れた日数を、街は眠って過ごしている。**手記の頁数だけが、彼女と街の両方の暦になっている。**

### 6-4. 手記
- 起源は街の作法(2-2)。彼女はそれを病人ではなく灯守として守ってきた——毎朝「夢は見なかった」と書くために。
- **二種の頁**: **魔物の頁**(図鑑。種族ごと。だ・である調、台詞なし、取り消し線と欄外注記、追記三は途切れる——既存 `CODEX` の書式)と、**日々の頁**(層ごとの覚え書きと毎朝の一行。物語文が扱う)。
- 書く場所は降り口の灯りの下(地表の自室ではない。一日一層で降り続ける以上、夜に地表へは戻れない)。
- 「夢は見なかった」の一行は、**本人の認知の外で嘘に変わり続ける**。彼女はそれを嘘だと知る形で書かない。欄外の「あまい」、本文の取り消し線、途切れた行、震えた絵——**嘘を証すのは字のほうで、本人ではない**。
- 淫気は熱と覚えを喰うが、紙とインクは喰わない。手記は身体の外に置かれた記憶で、街の作法が最初から彼女に持たせたものだ。

### 6-5. 世代差分の小道具一覧(初代と二世代目以降で必ず変える一行)
| 層 | 初代 | 二世代目以降 |
|---|---|---|
| 入口 | へこみは冷たい。石に線は無い | へこみの一つが温かい。石に正の字(世代数)。自分の追記を読む朝 |
| 水鏡 | 半拍遅れる像に初めて気づく | 錆びた髪留めが沈んでいる |
| 花園 | 欄外の「あまい」を塗り消す | 本文の「~~甘い~~ 使える」を読む→同じ線を引く→三世代目以降は線を消さない |
| 回廊 | 爪の線は見知らぬ者の跡。彼女の石の記録は短い | 爪の線は自分の字。石の記録が伸びている |
| 肉の巣 | 脈光に街の夢=自分が映る | 前の世代の自分と並べて数が出る |
| 朝(入口) | — | 「追記三」を読む。「病気の人たちとは、ちがう」 |

## 7. 結末(魔核討伐)と、その後の再開

### 7-1. 討伐
- 魔核は避けもせず、抗いもしない——夢を見ているだけの心臓に、光が届く。脈が止まり、深淵の息が止まる。
- 層を昇る間、壁の肉は冷えて石になり、花は閉じ、水鏡は何も映さなくなる。入口の苔のへこみは、朝の光で乾いた形だけになる。
- 地上では夜明けに街じゅうが目を覚ます。寝具は乾いていて、誰も夢を覚えていない。洞の口に眠る者はいない。先代も起きて、ただ長く寝たあとのように腰を伸ばす。
- **誰も彼女に礼を言わない**——何があったのか、誰も知らないからだ。薬師の帳面に「全快、原因不明」と書かれる。街の大人は灯守の娘を見るとなぜか頬が熱くなり、目を逸らす。理由は誰にもない。
- 彼女はその夜、いつもの一行を書く。「夢は見なかった」。書いてから初めて、下腹の奥に脈の拍がまだ残っていることに気づき、それを「疲れ」と書く。**淫気が最も長く住んだのは街の誰でもなく彼女で、心臓を止めても、住んだあとの部屋は残る。**

### 7-2. 深淵は死なない(再開)
- 討たれた夜は寝返りを打っただけで、層は組み直され、遠い底で**新しい心臓がもっと深く、もっと遅く、もっと厚く**脈を打ちはじめる(実装: 世代が進むほど魔核の HP が増す。地形の種も世代×階層で変わる)。
- 街がふたたび寝過ごす朝、彼女はまた降りる。石棚に一本刻む。**手記は、彼女が覚えている枚数よりもう厚い。**
- 討伐後の世代も、入口の頁の朝は 6-3 と同じ形で書く。違いは一つ——石棚の線の脇に、彼女が覚えていない小さな丸(討伐の印)が刻まれている。彼女はそれを「先代の印の、別の書き方」だと思う。

### 7-3. 最深部での敗北
- 最深部で二度落ちれば、深淵は彼女を**最も深い眠りから**吐き戻す。入口で目覚める朝、街は一番深く眠っている。世代は、そこから始まる。
- 「終わり」とは書かない。深淵にとって終わりは無く、彼女にとっての終わりは「入口で目を覚ますこと」で、本人はそれを終わりだと知らない。結果画面の地の文だけが、街の眠りの深さで終わりの形を示す。

## 8. 文章の禁則

### 8-1. NG(描写だけでなく、物語設定にも持ち込まない)
流血 / 殴打・アザ・痛そうな描写・痛喘ぎ(「ひぎぃ」「あ゛」系) / 四足獣姦 / 産卵・産み付け / 実在の昆虫(蟲型ワームは可) / 皮下寄生 / 巨大巨根 / 搾乳 / スカトロ / 妊娠・妊婦・赤子 / ゴブリン以外の人型異種 / 台詞のない地の文だけの凌辱 / 家族NTR(先代は師であって身内ではないが、先代を性的な場面の主体にしない。寝息と寝言だけ)。

### 8-2. 年齢
- 登場人物は全員成人。ルミナは成人(十九)。街の子供は物語に不在(2-1)。「子供みたい」「幼い」という語を地の文で彼女に使わない。幼さは崩れたときの語彙と語尾でだけ表す。

### 8-3. 声
- 一人称は私、崩れであたし。語尾は だよ/じゃん/だし。典型的女性口調(〜だわ/〜のよ)禁止。武家語・古語・祈り言葉の混入禁止。
- 説明台詞禁止。彼女は因果を説明しない。「夢の病」「深淵」「灯の掟」は地の文か街の人の言葉で立て、彼女は自分の目に映るものだけを言う。
- 設計語彙(crave帯・白状装置・参照先・堕ち帯・観測者・淫気)を本文・台詞・手記に出さない。総評の筆でも「淫気」は「息」と書く。
- 彼女は「催眠」を自分で名指ししない。代替: 「光を見た」「ぼうっとした」「覚えてない」「疲れてただけ」。手記・自己評価・台詞のすべてで。
- 魔核は喋らない。思考も書かない。「脈で言う」「寝返りを打つ」「寝息」だけ。
- 夜の目(プレイヤー)に身体・声・名を与えない。彼女が夜の目を見ることもない。気配・筆跡・「読まれている」感覚まで。
- 名乗りの全文は固定(3-5)。崩れは途切れ・言い直し・先に言われることで表す。別の文言に変えない。

### 8-4. ♡と喘ぎ
- ♡は**壊れ/懇願の行にだけ**(聖書の wreck / plea / afterHot 帯)。語尾連発禁止。地の文に書かない。**小淫魔の煽り台詞は例外**(多用可)。
- 物語文では第三層まで♡を置かない(小淫魔の台詞を除く)。第四層も置かない(言葉が出ないだけで、懇願ではない)。第五層でのみ許す。
- 喘ぎはひらがな。崩壊は「語彙→母音→記号」の順。三点リーダは「……」。

### 8-5. 最後の一行
- 全ての場面・全ての物語文・全ての手記の頁は、**矜持・自嘲・言い訳のどれかで締める**。完全勝利も完全敗北もさせない。
- 討伐の結末も例外ではない(「疲れ」の一語で締める)。リセットの朝も(「病気の人たちとは、ちがうし」)。
- 「夢は見なかった」の一行は毎朝必ず書かせる。本人がそれを嘘だと知る形では書かせない(認知ルール)。嘘を証すのは字と欄外と総評であって、本人の告白ではない。

### 8-6. 地の文と手記
- 地の文は常体・短文・読点間引き。部位名は言い切る(陰核・膣口・乳首・秘裂・内壁)。婉曲は台詞と手記の中だけ。
- 手記(魔物の頁)はだ・である調、台詞なし。取り消し線は追記に一つまで(追記三は乱れ可)。欄外※で本音が漏れる。
- 「無様だ」と書かない。無様な事実(迎え腰・涎・数えられる声・同じ場所に二度立つこと)を置いて読者に判定させる。

### 8-7. 反復と流用
- 同じ層の物語文は、初回/再挑戦/初代/二世代目以降で**別の本文**にする。朝の言い訳は2〜3の変奏をプールする。
- 他ヒロイン(遙・エレシア・玉藻)の既存装置をそのまま流用しない(祈りが解錠句になる、等)。本作の錠は**名乗り**、本作の白状は**読み上げと取り消し線**。
- 既存の図鑑本文・敗北本文の文をコピーしない。空気だけ吸って新しく書く。

### 8-8. lint(機械検査の対象)
禁止語(催眠/淫気/魅了/crave/白状/参照先/だわ/のよ)の本文出現、♡の位置(第五層・小淫魔・壊れ行以外)、名乗り全文の改変、街の名・先代の名・本名の出現、「子供」「幼い」の地の文出現、NG語彙。
