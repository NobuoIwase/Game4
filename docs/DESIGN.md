# 設計仕様 — ルミナ・サバイバーズ v0.2「侵蝕デッキ」

システム面の設計メモ。数値はすべて暫定で、`js/data.js` の `BAL` / 各定義テーブルに集約してある。

## 1. コンセプト(確定事項)

- ヒロイン(ルミナ)は**ゲーム内AIが完全制御**。プレイヤーは操作しない
- プレイヤーは**モンスター側**。ただし直接操作ではなく、**事前に組んだデッキから設置・召喚**して差し向ける
- ヒロインはヴァンサバ同様、武器/パッシブをレベルアップ・宝箱で獲得し、**融合**で強化される
- プレイヤー側に戦闘中のレベルアップはない。**モンスターと出現方法(陣形)を選んでコストを支払う**
- ヒロインに魔物が倒されるとエネルギーが増える。彼女の成長(Lv)に応じてEN上限も上がり、
  強い魔物・大きな出し方が戦闘中に可能になる
- ヒロインは非常に強力(高い護り+回復)。**初期状態ではダメージがほぼ通らない**。
  プレイヤーは周回でエッセンス→解放/強化/融合、オーブ→初期状態の書き換えを進める
- **数戦(GEN_LEN=4)ごとにヒロインの戦闘経験はリセット**され、常に新鮮な状態と戦える。
  例外として**オーブによる書き換えだけが世代を跨いで永続**する
- オートプレイあり(既定ON)。放置観戦でも進む

## 2. ループ構造

```
[ホーム] → 出撃 → [3分戦闘] → リザルト → 研究所/祭壇/編成 → 出撃 …
                     │
                     ├ 彼女が魔物を倒す → EN還元 + エッセンス + 彼女のXP(リスク)
                     ├ 与ダメ45ごと/異常付与ごと → オーブ片
                     └ HP0 → 捕獲(オーブ大) / 3:00生存 → 彼女の勝ち(エッセンスボーナス)
世代: 4戦で経験リセット(世代内は装備・HP・護りを継承して強くなる)
```

飼い慣らしのジレンマ: 魔物を撒くほど経済は回るが、彼女に経験値を与えて育ててしまう。

## 3. 状態異常(機構仕様)

idは汎用カタログ準拠。効果はすべて数値・挙動レベルで表現する。

| id | 名 | 付与元 | 機構 |
|---|---|---|---|
| bound | 拘束 | 縛鎖ワーム/触手花/大触手/ボス突進 | 移動不能・攻撃55%・被ダメ×1.6・護り半減・**ifr短縮**。もがき(レベル依存)で短縮。**周囲の魔物が群がる(速度×1.9)** — 「仕留めの窓」 |
| aphrodisia | 発情 | 小淫魔ダート/宵闇こうもり | 0-100蓄積・自然減衰。集中低下(操舵鈍化+ノイズ)、70+でふらつき(0.35s停止)、50+でもがき-30% |
| slow | 粘液 | スライムの跡 | 速度55% |
| charm | 魅了 | 小淫魔(3投に1回) | 対象を攻撃・回避の対象から除外 |

- 耐性: 同種を受けるたび一時耐性が付き効果減(時間で減衰) → 連発の抑止
- 祭壇「感応増幅」は sense 倍率で全異常を深くする
- dot(触手花)は護り貫通

## 4. 経済

| 資源 | 入手 | 用途 |
|---|---|---|
| EN(戦闘内) | 自然回復+彼女の撃破還元(単価×0.6)。上限=10+2×彼女Lv | カード召喚(コスト=カード基礎×陣形係数) |
| エッセンス | 彼女が倒した魔物のxp×0.55+勝敗ボーナス | 解放・強化(Lv5まで)・融合・陣形解放 |
| オーブ | 与ダメ45ごと+異常付与ごと(2sレート制限)+捕獲20+世代内戦歴×5 | 祭壇(初期状態の書き換え・永続) |

## 5. ヒロイン仕様

- 基礎: HP120 / 護り5 / 回復0.55/s / 速度150。**世代内戦歴nで** HP+18%n・護り+n・回復+0.15n・初期装備追加
- AI: 脅威回避(潜航中ワーム・未発見の花は見えない)/ジェム・ハート・宝箱回収/カイト。
  発情で操舵にノイズ、拘束・ふらつきで停止
- 武器融合(進化): base武器Lv5+ペアパッシブLv2 → レベルアップ択/宝箱で解禁
  - bolt×speed→シューティングスター / orb×vital→セイクリッドリング / nova×magnet→スターバースト
- 捕獲=HP0(死亡ではなく制圧)。捕獲シークエンス→リザルト

## 6. テキストパイプラインとの分業

**システム側(本リポジトリのコード)は機構・数値・非明示的な演出のみを扱う。**
本文テキスト(捕獲シーン、称号、総評など)は別途の執筆パイプラインが担当し、
以下のフックに差し込む:

- `js/scenes.js` — `SCENES.capture[<monsterId>] = {title, beats:[]}`。
  未定義時は機構的リザルトのみ表示(現状すべて未定義)
- 観測記録画面 — 称号/総評カードは将来の拡張ポイント(汎用カタログ第五章の並び順に準拠予定)
- 堕ち二軸(肉体/精神)の段階名はカタログ準拠(不惑→…→崩れ / 不動→…→明け渡し)。
  世代リセットで戻る(=「堕ちきらない」設計)

### 運用上の前提

- 登場キャラクターは**全員成人**(汎用カタログの前提と同一)。ルミナは成人として扱う
- 幼さ・未成年性を性的文脈で示唆する要素(学齢表記・体格記号等)は、
  システム側・テキスト側とも**実装対象外**

## 7. バランス調整メモ(テストプレイ結果)

- 素の初期デッキ(こうもり/スライム/ゴースト)では3分間で与ダメ0が正常(護り5に対し攻4-7)
- 初オーブはゾンビ解放(120)後。5戦時点でオーブ~10、祭壇初回購入は5-6戦目
- 育成後(カードLv3-4+祭壇2段)で捕獲30秒台を確認
- オート指揮は「拘束役の維持→拘束が入った瞬間に重打を連打」を最優先で行う
- 反復抑止・尾引き(翌戦への影響)系はv0.3候補: 同一カード連打のコスト逓増、
  捕獲後の次戦デバフ持ち越し、モンスター側の「学習」など
