# v3.0 執筆仕様 — フレイラ(新ヒロイン)とパーティの文章

この文書は「執筆者(Opus)」向けの発注書。システム側(キー・形式・器)はこの通りに固定してある。

## 0. 必読
1. `統合嗜好プロファイル (2).md` 全体。特に **第三部-B(実例つきの書式仕様)**、**第五部(新ヒロインを作る＋声の文法表)**、NG一覧。
2. 既存の参考文: `js/lines.js`(ルミナのマップ台詞。短い・ひらがな多め・元気)、`js/scenes.js` と `js/scenes_v20.js`(押し倒しビートと敗北本文の実物)、`js/story.js`(ADVの形式と、見習いの天使という設定)。
3. 設定の要点: 街の外れの丘の祠から降りてくる**見習いの天使**。ルミナ(光の投射武器・元気っ子・「だよ/だし」)は主人公。夜側(プレイヤー)は魔物を召喚してヒロインを捕まえる側。捕まると「敗北の本文」(長文)が流れる。ヒロインは**催眠**という単語を口にしない。

## 1. フレイラ(Freila)の声の設計
- 火を操る**近接主体**の天使。ルミナと同じ祠の、ひとつ上の見習い。**気が強い**、負けず嫌い、面倒見はいいが口が悪い。前に出て燃やす。
- 見た目: 赤いボブ、光輪、白い翼と白いマント、赤い衣に金の縁と胸のリボン、赤いブーツ。
- 一人称「わたし」。ルミナを「ルミナ」、突き放す時は「あんた」。魔物は「こいつ」「おまえ」「こんなの」。
- **禁止の語尾**: 「〜だわ」「〜わよ」「〜のよ」「〜わね」「〜かしら」「〜ですわ」など**女言葉のテンプレは一切使わない**。文末の「〜よ」も使わない(「行くよ」ではなく「行く」)。「〜だろ」「〜ぜ」も使わない(男言葉にもしない)。
- 使う型: 断定・命令の短文。「行く」「下がって」「燃やす」「うるさい」「……っ、まだ」「そこ、どいて」「勝手にしなさい」「〜でしょ」「〜じゃない(否定)」「〜って言ってる」。ルミナのような「だよ/だし/♪」は使わない。
- 火の比喩で心の温度を書く: 火種・熾火・煤・燻る・炙られる・消える・くすぶる。強気が折れる過程は**命令形が疑問形に崩れる**(「離せ」→「はな……して……?」)、悪態が独り言に、火が小さくなっていく。
- 最後の一行は**負け惜しみ**か**「ルミナに見せられない」矜持**で締める(プロファイル第三部の原則)。
- **♡はフレイラの台詞では原則禁止**。使えるのは敗北本文の最終ビートで最大1個。ルミナの台詞での♡の扱いは既存どおり(小淫魔の煽り台詞のみ)。
- NG厳守: 流血/痛喘ぎ/産卵/獣姦/実在の昆虫/皮下寄生/巨根/搾乳/スカトロ/妊娠。「催眠」という語はヒロインの口から出ない(「変な光」「頭がぼやける」で表す)。

## 2. 二人の関係(パーティ)
- 相談して決める。意見が割れたら**どちらかに従い、負けた方の意見が次は優先**される(システムが管理。台詞は「提案」「賛成」「譲る」「押し通す」「同じ考え」の型で書く)。
- 互いをカバーする: 掴まれた方を剥がしに行く、押し倒された方の相手を燃やす/撃つ、体力が薄い方にハートを譲る、捕まった方を救出する(そばに3秒立つ)。
- 一人が捕まった時、残った方は「救出」か「置いて降りる」を選ぶ。全員捕まると敗北。
- 画面外のことも共有する: 「あっちにボスみたいなのがいる」「あっちに何かある」。
- 雑談: 静かな時間の二人のやりとり(2行)。性格の対比(元気な後輩/口の悪い先輩)を出す。

## 3. 出力の形式(JSON)
すべて UTF-8 の JSON。**文字列の中に改行を入れるときは `\n`**。ビート(押し倒し)は1行50文字以内(canvas に1行で描く)。敗北本文は複数行可。
話者付きの行は `{"s":"lumina"|"freila"|"n"|"voice"|"town","t":"本文","f":"heat|shy"(任意)}`。

### 3-1. パーティ台詞 `lines_party.json`(担当A)
```
{
 "propose": { "<kind>": { "lumina": ["…","…","…"], "freila": ["…","…","…"] } },   // kind = chest, boss, shrine, spring, pool, stele, stairs, core, explore, gems, event, shroom, nectar, treasure, seal, item, rescue
 "agree":   { "lumina": [4本], "freila": [4本] },        // 相手の案に乗る
 "yield":   { "lumina": [4本], "freila": [4本] },        // 負けたが従う(「次はわたし」)
 "insist":  { "lumina": [4本], "freila": [4本] },        // 押し通す側
 "same":    { "lumina": [3本], "freila": [3本] },        // 同じ案だった
 "assist":  { "grab": {"lumina":[4],"freila":[4]}, "pin": {"lumina":[4],"freila":[4]}, "low": {"lumina":[4],"freila":[4]} },   // 相手が掴まれた/押し倒された/体力が薄い
 "heartYield": { "lumina": [3], "freila": [3] },        // ハートを譲る
 "rescue":  { "start": {"lumina":[3],"freila":[3]}, "done": {"lumina":[3],"freila":[3]}, "thanks": {"lumina":[3],"freila":[3]} },
 "captured": { "watch": {"lumina":[4],"freila":[4]}, "alone": {"lumina":[4],"freila":[4]}, "leave": {"lumina":[3],"freila":[3]} },   // 相手が捕まるのを見た/一人で戦う/置いて降りる

```
一本の台詞は 4〜22 文字目安。ルミナはひらがな多め、フレイラは漢字が少し多く短い。

### 3-2. フレイラ単独の台詞 `lines_freila.json`(担当B)
`js/lines.js` の `LINES` と同じキー構成をフレイラの声で。必要なキー: `mon.<id>.see` と `mon.<id>.know`(MONSTERS の全種: js/data.js を見る。item:true の web/tower も含めてよい)、`event.*`、`poi.*`、`pick.*`、`floor.<1..8>`、`feat.*`、`pressure.mid/high`、`wantExit`、`stairsWait`、`guarded`、`sentinel.*`、`explore`、`exploreDone`、`exploreNew`、`gemWalk`、`hurtLow`、`calm`、`giveUp`、`gemFast`、`hesitate`、`hesitateAgain`、`brave`、`braveFinally`、`chicken`、`resign`、`abort`、`skill.{blaze,ember,phoenix}`(奥義: 火の突進/燃える壁/不死鳥の起き上がり)、`retreat`、`kite`、`bossPick`、`fleeExit`。各キー 2〜4 本。lines.js の各キーの意味は同ファイルの注釈と使用箇所(js/game.js の sayLine)で確認。

### 3-3. フレイラの押し倒し/敗北 `scenes_freila_<1|2|3>.json`(担当C/D/E)
```
{ "pin": { "<id>": { "beats": [6本、各50文字以内] } }, "capture": { "<id>": { "title": "…", "beats": [8〜10本。\n可] } }, "charmbind": { "default": {...} }, "climax": { "default": { "beats": [...] } } }
```
- 担当C: worm, flower, gtent, ghost, slug, gas, imp, slime, mistslime, goblin, leech, vampi
- 担当D: hand, serpent, moth, pot, slugqueen, dreamtree, spore, ghosthand, eye, succubus, web, gazer
- 担当E: bossgazer, beamer, slimeking, runemage, succuqueen, gobking, inyoku, suiyou, mouth, guardian, core, sentinel, default(+ charmbind.default と climax.default)
- `capture` は全種。`pin` は SCENES.pin / SCENES_v20 に存在する種だけ(同じ種を見る)。
- ルミナの本文と**同じ長さ・同じ構造**(耐えている間の分解能、絶頂は句読点、最後は矜持/負け惜しみ)。フレイラは近接なので**火が届かない距離に押し込まれる/掴まれて手が使えない**が敗因になりやすい。
- 二人設定を意識: ルミナの名を呼ぶ・見られたくない・「ルミナだけは行かせる」等の一行を各本文に1〜2箇所。

### 3-4. 物語(ADV) `story_v30.json`(担当F)
```
{
 "prologue": [ {s,t}… ],                         // 序章の書き直し: 二人で降りてくる。20〜30行。ルミナの元気とフレイラの口の悪さ、二人の関係(同じ祠、ひとつ上)を立てる。既存の prologue(js/story.js)の設定を引き継ぐ(灯守ではなく天使、街を守る、夢は見ない)
 "floors": { "6": {intro:[8〜12], enter:[3], descend:[3]}, "7": {...}, "8": {...} },   // 6 骸の回廊(骨と煉瓦、番人の多い遺跡) / 7 星の湖底(星明かりの湖、浅瀬と水妖) / 8 深淵の底(肉と紋、最深部)
 "party": { "rescue": [4〜6行], "leftBehind": [4〜6行], "bothCaptured": [4〜6行], "reunion": [4〜6行], "join": [6〜10行: フレイラが合流する場面(初回)] },
 "era": { "coreDown": [ [6〜10行] ×3 ],   // 魔核を討った直後。1本目=初めて(弱い魔核)、2本目=二度目、3本目=三度目以降(深淵が組み替わり、より深く・より強く)
          "loopIntro": [4〜6行] }          // 組み替わった後、入口に戻った朝
}
```
ADV は「」で話者の台詞、地の文は s:"n"。1行は 40〜70 文字。ルミナ「じゃん」は全体で2回まで。フレイラは禁止語尾に注意。

## 4. 自己点検(提出前)
- 禁止語尾の検索: フレイラの行に `だわ|わよ|のよ|わね|かしら|ですわ|よ」|よ。|だろ|ぜ」` が無い。
- NG語の検索: `血|痛|卵|獣|虫|皮下|巨根|搾乳|妊娠|催眠`(ヒロインの発話)。
- ♡: フレイラの行は敗北本文の最終ビート以外に無い。
- JSON が妥当(全体を1つのオブジェクトで、末尾カンマ無し)。
